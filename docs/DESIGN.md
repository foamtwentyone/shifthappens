# SHIFT HAPPENS — дизайн-документ демо

## 1. Столп игры

**Игроки создают свои смешные истории через физику и взаимосвязи.** Любая механика
должна (а) иметь понятную производственную задачу, (б) влиять хотя бы на одну другую
механику, (в) давать возможность красиво провалиться.

Приоритеты: интересный процесс → настоящая кооперация → узнаваемый стиль →
интерфейс → стабильная техника → расширяемость.

## 2. Локация: Завод №7

```
                    ┌────── CONTROL ROOM ──────┐
                    │ щит питания  котёл+вентиль│
┌─ BREAK ROOM ─┬── INTAKE ──┬──── SORTING ─────┬AIRLOCK┬────── DOCK ──────┐
│ контракты    │ раздатчик  │ сканер→сортировщик│ двери │ площадки A/B     │
│ риски        │  ═══ лента A ═══►[S]═══ лента B ═══════►  лифт, фан,     │
│ шкафчики     │ мусоросжиг.│ тостер ║лента C   │       │ магнит, SKY DOCK │
│ табель       │            │   труба ╚═══════════════════════════► (C)    │
└──────────────┴────────────┴───────────────────┴───────┴──────────────────┘
```

Пять производственных помещений + комната отдыха. Камера смотрит с юга под углом, поэтому
южные стены низкие (с высоким невидимым коллайдером), северные — высокие с трубами и
табличками.

## 3. Системы и их связи

| Система | Зависит от | Влияет на |
|---|---|---|
| Питание (3 зоны + MAIN) | давление (взрыв → блэкаут) | всё, что движется |
| Котёл (давление 0–100) | число включённых зон, сверхурочные | скорость лент, трубы, фана; перегрев; взрыв |
| Лента A / B / C | питание зоны, давление, рычаг направления | затор при >7 грузов, сортировщик |
| Сканер | питание сортировки | адрес загадочных ящиков → маршрут сортировщика |
| Сортировщик | питание, режим, неисправность | маршрут: лента B или труба |
| Шлюз | питание дока (без него — ручной привод) | проход людей и ленты B; при обеих открытых — сквозняк |
| Пневмотруба | питание, перегрев, давление | доставка на Sky Dock; бьёт гномов на высоком давлении; возит людей |
| Лифт / Фан / Магнит | питание дока | три альтернативных пути на Sky Dock |
| Тостер | питание сортировки | бобы (обязательный нагрев) |
| Перегретая машина | давление >85 долго | машина стоит, нагревает бобы рядом |

**Примеры цепочек, которые возникают без сценария:**
никто не следит за котлом → 85+ PSI → перегрев трубы → грузы копятся у хоппера →
кто-то выключает питание сортировки → ленты A встаёт → раздатчик на AUTO продолжает
сыпать → затор → взрыв котла → блэкаут → в темноте все бегут в диспетчерскую, а
горячие бобы выпрыгивают из рук.

## 4. Грузы

| Груз | Площадка | Физика | Кооперативный момент |
|---|---|---|---|
| Steel Crate | A | 60 кг, соло только волоком (×0.38 скорости) | вдвоём ×0.9, вдвоём бросить «раз-два-взяли» |
| Wobble Drum | A | центр тяжести «плещется»: рывки носильщика | вдвоём рывки делятся |
| Porcelain Gnome | B | бьётся при ударе > 7 м/с и в трубе при давлении | ловить брошенного гнома |
| Thermo Beans | B | нужен нагрев ≥ 0.4; горячие прыгают и сбивают | эстафета «тостер → шлюз → B» |
| Helium Parcel | C | гравитация ×0.12; фан и сквозняк уносят | фан как лифт на Sky Dock |
| Magnetic Core | C | тянется к магниту/ядрам/ящикам | один включает магнит, другой подносит |
| Mystery Box | ? | адрес открывается сканером | нужен проход по ленте A |
| Rubber Duck | — | мусор, засоряет | сжечь (+$5) |

## 5. Кооператив

- **Нужно больше рук:** тяжёлые грузы, ремонт быстрее вдвоём, вентиль быстрее вдвоём,
  главный автомат «на две руки» (соло — в 2.2 раза медленнее).
- **Разные точки управления одной системой:** шлюз управляется с обеих сторон, лифт —
  снизу и сверху, питание — только из диспетчерской, давление — видно только там же.
- **Асимметричная информация:** точное давление только на манометре; адрес загадочного
  ящика — только после сканера; в контракте Lights Out видно лишь то, что освещено
  фонариками.
- **Мешать друг другу можно:** толчок, броски коллег, сбивание грузом, E-STOP в чужой
  зоне, переключение рычага не в ту сторону.
- **Соло возможно:** квоты ×0.7, давление растёт медленнее, аварий меньше.

## 6. Риск и награда — внутри мира

- **Рискованные условия** — физические рычаги на красной стене комнаты отдыха.
  Подписал — растёт множитель оплаты, видят все.
- **Телефон начальника** — физические рычаги CLOCK OUT / OVERTIME в доке, их надо
  удерживать (это осознанное командное решение, а не случайный клик). Сверхурочные:
  новый мини-заказ, +время, ×1.5 оплаты, аварии чаще; провал — минус половина бонуса.
- **E-STOP** мгновенно чинит зону, но стоит денег и 4 секунды простоя.
- **Давление** — постоянная ставка: быстрее производство vs. риск взрыва.
- **Рост бюджета** открывает более сложные и дорогие контракты (tier 0–3).

## 7. Арт-дирекшн

- Игрушечный индустриальный минимализм: скруглённые примитивы, крупные кнопки и
  рычаги, чернильный контур (inverted hull) у персонажей и грузов, мягкий солнечный
  свет + небесный заполняющий, ACES tone mapping, лёгкая металличность.
- Палитра: Safety Yellow `#ffc93c`, Factory Teal `#1f8a8a`, Hazard Orange `#ff7a2f`,
  Signal Red `#e8423f`, Ink `#1b1f24`, Paper `#f4ebd9`. Цвет бэя = цвет значка над
  грузом = цвет площадки = цвет в HUD.
- Рабочие («Shifties»): большая голова, короткие конечности, огромный комбинезон с
  нагрудником, жёлтые рабочие перчатки — фирменная деталь. 8 цветов, 7 головных уборов
  (каска, шапка, кепка, дорожный конус, бумажная шляпа, сварочная маска, без), 4 лица.
- Процедурная анимация с перебором: сжатие при приземлении, пружинный «флоп» при
  падении, размахивание руками в полёте, перенос, работа с механизмами.

## 8. Дизайн-система интерфейса «PLANT 7»

Каждый элемент интерфейса — физический предмет с завода: клёпаная стальная панель,
тумблер, лента лейбл-принтера, ЖК-табло, резиновая печать, бумага на планшете,
предупреждающая штриховка. Шрифты: Bungee (вывески), Rubik (текст), Space Mono
(табло, этикетки). Меню — тумблеры на панели управления поверх стола начальника смены;
отчёт — форма 7B с печатью результата; номинации — значки с портретами, отрендеренными
в реальном времени из 3D-модели.

## 9. Сеть

- **Авторитарный сервер:** вся физика и правила на сервере (60 Гц), клиенты шлют
  только ввод: оси, удерживаемые кнопки (бег, использовать) и **счётчики нажатий**
  (прыжок, взять, использовать, бросить) — нажатие не теряется между пакетами.
- **Снапшоты** 20 Гц (локально 30 Гц) с событиями (звуки, эффекты, деньги, аварии),
  интерполяция на клиенте с задержкой 110 мс (локально 45 мс).
- **Отключение:** персонаж становится полупрозрачным и остаётся 30 с; повторный вход с
  тем же токеном (sessionStorage) возвращает управление. Пустые комнаты закрываются.
- **Локальный режим** запускает тот же `Room` в браузере — один и тот же код.
