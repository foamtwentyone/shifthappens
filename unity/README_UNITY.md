# SHIFT HAPPENS — Unity-версия (Unity 6, URP)

Порт веб-версии на Unity 6: та же симуляция (физика PhysX, машины, аварии, контракты,
сверхурочные, отчёт), сеть через Netcode for GameObjects, URP с пост-обработкой,
ассеты Kenney (CC0) с анимированными персонажами, интерфейс на UI Toolkit.

> **Статус: первая сборка, ещё ни разу не запускалась в редакторе.**
> Код писался без Unity Editor (в облачном окружении его нет). Весь C# проверен
> компилятором против референсных сборок UnityEngine 2021.3 и заглушек API пакетов, но
> запуск, импорт моделей и картинку можно проверить только у вас. Ожидаемы мелкие
> правки после первого открытия — присылайте ошибки из Console и скриншоты.

## Установка (один раз)

1. **Unity Hub → New project → шаблон «Universal 3D»** (Unity 6 LTS). Назовите как
   угодно, например `ShiftHappens`. Шаблон сразу настраивает URP и Input System.
2. **Window → Package Manager → `+` → Add package by name…** →
   `com.unity.netcode.gameobjects` → Add. (Unity Transport подтянется сам.)
3. Скопируйте папку **`unity/Assets/ShiftHappens`** из этого репозитория в папку
   `Assets` нового проекта. Unity импортирует модели (~1–2 минуты).
4. Откройте любую сцену (подойдёт `SampleScene` из шаблона) и нажмите **Play**.
   Игра сама создаёт камеру, свет, уровень и интерфейс — в сцене ничего настраивать не нужно.

Если проект создан не из URP-шаблона, скрипт `Shift Happens → Re-run project setup`
попробует сам создать и назначить URP-ассет (с SSAO).

## Управление

| Действие | Клавиатура 1 | Клавиатура 2 (диванный игрок) | Геймпад |
|---|---|---|---|
| Движение | WASD | Стрелки | Левый стик |
| Бег | Left Shift | Right Shift | RT |
| Прыжок | Space | Enter | A |
| Взять / бросить | E | `.` | X |
| Использовать (удерживать) | F | `/` | B |
| Метнуть / толкнуть | Q | `,` | Y |
| Пауза | Esc | Esc | — |

В комнате отдыха второй игрок на клавиатуре жмёт `Enter`, геймпад — `Start`.

## Мультиплеер

- **По локальной сети:** START SHIFT → HOST (LAN). В комнате отдыха показан IP хоста.
  Друзья: JOIN FRIENDS → вводят этот адрес. Порт UDP **7777** (Windows спросит
  разрешение для брандмауэра — разрешите).
- **Через интернет без проброса портов (Unity Relay):**
  1. Package Manager → установить `com.unity.services.multiplayer`.
  2. Edit → Project Settings → Services: привязать проект к Unity Cloud (бесплатно).
  3. Project Settings → Player → Scripting Define Symbols: добавить `SH_RELAY`.
  4. START SHIFT → HOST (INTERNET) выдаст 6-символьный код; друзья вводят его в JOIN FRIENDS.

  Relay-код в `NetBridge.cs` не проходил даже проверку компиляции (нет заглушек для
  сервисов Unity) — если после добавления `SH_RELAY` появятся ошибки, пришлите их.

## Как устроено

```
Assets/ShiftHappens/
  Scripts/Runtime/
    App.cs            загрузчик: создаётся сам при Play, связывает всё остальное
    Defs.cs           данные: грузы, риски, геометрия Завода №7
    Sim/              авторитарная симуляция (только на хосте): Sim, Plant, Game
    Net/              бинарные снапшоты, Room (хост), Session (клиент, интерполяция), NetBridge (Netcode)
    Input/            две раскладки клавиатуры + геймпады (Input System или старый Input Manager)
    View/             камера и пост-обработка, окружение, персонажи (Playables), грузы, частицы
    UI/               дизайн-система PLANT 7 на UI Toolkit, все экраны, ламповые табло
    Audio/            синтезированные звуки и музыка
  Scripts/Editor/     автонастройка URP, правила импорта моделей Kenney
  Resources/Kenney/   модели FBX (CC0) + перекрашенные палитры
  Resources/Fonts/    Bungee, Rubik, Space Mono, Caveat (OFL)
```

Симуляция хранит координаты веб-версии; визуальный слой зеркалит ось Z
(`View/ViewSpace.cs`), иначе в левосторонней системе Unity завод отображался бы зеркально.

## Что проверить при первом запуске (и прислать мне)

1. **Console** после импорта и после нажатия Play — все ошибки и предупреждения.
2. Скриншоты: меню, комната отдыха с персонажем, цех во время смены.
3. Известные места, где возможны правки:
   - **Персонажи смотрят спиной вперёд** → в `View/Actors.cs` поменять `FacingOffset` на 180.
   - **Модели слишком большие или маленькие** → масштаб пакета считается по эталонной
     модели в `Kit` (`View/Art.cs`); пришлите скриншот.
   - **Шевроны на ленте едут не туда** → поправлю ориентацию текстуры.
   - **Персонаж не анимируется** → проверьте, что у FBX в `Resources/Kenney/characters`
     в инспекторе Rig = Generic (скрипт импорта ставит это сам).

## Отличия от веб-версии в этой сборке

- Меню — пролёт камеры над заводом (без стола начальника и демо-рабочих).
- В раздевалке и отчёте вместо 3D-портретов — цветные плашки с названием модели.
- Музыка — два заранее сгенерированных лупа (в вебе — адаптивный секвенсор).
