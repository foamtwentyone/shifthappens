# SHIFT HAPPENS — Plant 7 (playable demo)

Кооперативная физическая комедия для 1–4 игроков. Вы — работники Завода №7, который
сортирует и отгружает очень странные грузы. Механизмы связаны между собой, котёл
взрывается, гномы бьются, бобы прыгают, а начальник по телефону предлагает «ещё
немного сверхурочных».

Игра работает в браузере (Three.js + cannon-es), онлайн-режим — через
собственный авторитарный сервер на Node.js (WebSocket).

## Быстрый старт

```bash
npm install
```

```bash
npm start
```

Откройте **http://localhost:8080**. Друзья в той же сети заходят на `http://<ваш-IP>:8080`
→ **JOIN FRIENDS** → вводят 4-буквенный код комнаты.

Для игры через интернет нужен проброс порта 8080 или любой TCP/HTTP-туннель до вашего
компьютера (WebSocket идёт по тому же адресу, путь `/ws`).

### Режимы

| Режим | Как запустить | Что это |
|---|---|---|
| **Solo / Couch** | START SHIFT → SOLO / COUCH | Вся симуляция в браузере. Второй игрок на той же клавиатуре нажимает `ENTER` (стрелки), геймпады — `START`. До 4 игроков. |
| **Host online** | START SHIFT → HOST ONLINE | Комната на сервере, код комнаты показывается в комнате отдыха. |
| **Join friends** | JOIN FRIENDS | Вход по коду. Можно указать другой адрес сервера. |

### Разработка

```bash
npm run server
```

```bash
npm run dev
```

Vite (порт 5173) проксирует `/ws` на сервер (порт 8080). Тесты симуляции:

```bash
npm test
```

| Действие | Клавиатура 1 | Клавиатура 2 | Геймпад |
|---|---|---|---|
| Движение | WASD | Стрелки | Левый стик / крестовина |
| Бег | Left Shift | Right Shift | RT / LT / RB |
| Прыжок, вырваться из рук | Space | Enter | A |
| Взять / бросить / помочь нести | E | `.` | X |
| Использовать (удерживать для вентилей и ремонта) | F | `/` | B |
| Метнуть / толкнуть / «раз-два-взяли» | Q | `,` | Y |
| Пауза | Esc | Esc | Start |

## Как устроен раунд

1. **Комната отдыха (лобби).** Игроки ходят своими персонажами. На пробковой доске
   выбирают контракт, на красной стене подписывают рискованные условия (Rush Job,
   No Scratches, Lights Out, Cranky Gear) — каждое повышает оплату. В шкафчиках выбирают персонажа (20 моделей), командный цвет и головной убор
   (или через кнопку **LOCKER**). Когда все **отметились у
   табельных часов**, идёт обратный отсчёт и открываются ворота в цех.
2. **Смена.** Грузы появляются из раздатчика (кнопка REQUEST или AUTO-FEED), едут по
   ленте A через сканер к сортировщику, дальше — по ленте B через шлюз в док или по
   пневмотрубе на верхний причал (Sky Dock). Значок над грузом показывает, куда его
   нести: **A** и **B** — площадки в доке, **C** — Sky Dock.
3. **Аварии** — случайные и цепные (см. ниже). Их надо чинить руками.
4. **Решение.** Когда квота выполнена, звонит **телефон начальника** в доке. Рычаг
   CLOCK OUT забирает деньги, рычаг OVERTIME даёт новый заказ, больше времени, ×1.5
   к оплате и больше хаоса. Провалите сверхурочные — потеряете половину бонуса.
5. **Отчёт о смене** (Form 7B): заработок, повреждения, аварии, статистика игроков и
   номинации (Employee of the Shift, Walking Disaster, Most Expensive Mistake,
   Conveyor Victim, Frequent Flyer, Human Catapult…). Затем все возвращаются в комнату
   отдыха; заработок копится в общем бюджете, и с ростом бюджета открываются более
   сложные контракты.

## Что реализовано

- **7 типов грузов** со своей физикой: тяжёлые стальные ящики (в одиночку — только
  волоком), бочки с плещущейся жидкостью (дёргают носильщика), фарфоровые гномы
  (бьются от ударов и слишком быстрой трубы), термобобы (нужно прогреть под лампой;
  горячие прыгают), гелиевые посылки (почти не падают, их несёт вентилятор и сквозняк),
  магнитные ядра (тянутся к магниту, друг к другу и к стальным ящикам), загадочные
  ящики (адрес открывает сканер). Плюс мусорные утки и игрушки в комнате отдыха.
- **Связанные механизмы:** раздатчик, 3 конвейера с рычагами направления, сканер,
  сортировщик (AUTO / всё на B / всё в трубу), пневмотруба (возит и грузы, и людей),
  шлюз с блокировкой дверей, лифт, вентилятор-подъёмник, электромагнит, тостер для
  бобов, мусоросжигатель, щит питания (3 зоны + главный автомат), паровой котёл с
  вентилем, аварийные кнопки E-STOP.
- **Давление котла** — общий ресурс: чем выше давление, тем быстрее ленты, труба и
  вентилятор, но выше риск перегрева и взрыва. Точное значение видно **только на
  манометре** в диспетчерской (асимметричная информация).
- **10 типов аварий**, меняющих реальные условия: затор ленты, реверс ленты,
  блэкаут, безумие сортировщика (швыряется грузом), перегрев машины (и нагрев бобов
  рядом), гравитационная флуктуация зоны, разгерметизация шлюза (сквозняк уносит
  людей и груз), утиный завал, скачок давления, переполюсовка магнита.
  Цепочки возникают сами: давление → перегрев/взрыв → блэкаут → ленты стоят →
  грузы копятся → затор.
- **Кооператив:** совместный перенос (2–3 человека ускоряют тяжёлые грузы),
  совместный бросок, ремонт и вентиль быстрее вдвоём, главный автомат «на две руки»,
  можно поднимать и бросать коллег, толкаться, сбивать друг друга брошенными грузами.
  Соло проходимо (квоты масштабируются под число игроков).
- **Сеть:** авторитарный сервер со своей физикой, коды комнат, синхронизация движения,
  взаимодействий, физических объектов и событий, интерполяция снапшотов, переподключение
  в течение 30 с (персонаж остаётся «призраком»).
- **Интерфейс:** собственная дизайн-система PLANT 7 (клёпаные панели, тумблеры,
  ленты-этикетки, ЖК-табло, печати, планшеты), меню-«стол начальника смены» с живым
  заводом за ним, лобби, раздевалка, HUD, отчёт о смене, личное дело (рекорды),
  настройки.
- **Графика:** пост-обработка (GTAO ambient occlusion, HDR-bloom для ламп и экранов,
  ACES-тонмаппинг, цветокоррекция со split-toning, виньетка, лёгкое зерно, SMAA),
  отражения от окружения (image-based lighting), процедурные PBR-карты нормалей и
  шероховатости (бетонная плитка, стальные панели с заклёпками, штукатурка, рифлёная
  резина ленты, ткань комбинезонов, древесина), колонны, разметка проходов, решётки.
  Пресеты в Settings → Graphics: LOW (без пост-обработки и теней — для слабых ПК),
  MEDIUM (AO в половинном разрешении), HIGH (полное разрешение, тени 4096).
- **3D-ассеты Kenney (CC0):** 20 скинированных персонажей Mini Characters с анимациями
  (idle, ходьба, бег, прыжок, падение, «нокаут», перенос груза двумя руками, работа с
  механизмами); машины, сканер, хоппер, роботы-манипуляторы, шестерни, сигнальные башни и
  ящики из Factory Kit (палитра перекрашена в гамму Plant 7); промышленный квартал вокруг
  завода из City Kit Industrial (здания, трубы с дымом, водонапорная башня, контейнеры);
  каски и ящики из Prototype Kit. Ноги и руки анимируются раздельно: персонаж идёт и
  одновременно держит груз.
- **Звук:** всё синтезируется на лету — эффекты, «бормотание» рабочих, гул машин,
  адаптивная музыка (лаунж в меню, фанк в смене, ускорение в сверхурочные).

## Архитектура

```
shared/            ← одна и та же симуляция на сервере и в браузере
  constants.js     тюнинг, типы грузов, риски
  level.js         геометрия Завода №7 и расстановка всех механизмов (данные)
  room.js          комната: игроки, переподключение, фиксированный шаг, снапшоты
  sim/Sim.js       мир cannon-es, игроки, переноска/броски, грузы, столкновения
  sim/plant.js     машины, органы управления, аварии, давление, доставка
  sim/game.js      фазы смены, контракты, деньги, сверхурочные, отчёт, номинации
server/index.js    HTTP (раздаёт dist/) + WebSocket-комнаты
src/
  net/Session.js   LocalTransport (Room в браузере) / WebSocketTransport + интерполяция
  input/Input.js   две раскладки клавиатуры + геймпады, счётчики нажатий
  render/*         Three.js: окружение, процедурные модели, анимации, эффекты
  ui/*             меню, лобби, HUD, отчёт, хранилище настроек
  audio/Audio.js   синтез звука и музыки
tests/sim.test.js  14 тестов игрового цикла
```

Клиент никогда не трогает физику напрямую: и в одиночной игре, и онлайн он
отправляет ввод в `Room` и рисует полученные снапшоты. Поэтому одиночный режим и
онлайн проходят через один и тот же код.

## Честные ограничения демо

- **Нет клиентского предсказания.** Онлайн-персонаж реагирует с задержкой ≈ пинг +
  110 мс интерполяции. В локальной сети это почти незаметно, через океан —
  заметно. Архитектура позволяет добавить предсказание своего персонажа.
- **Нет NAT-traversal и мастер-сервера.** Хост запускает сервер и должен быть
  доступен друзьям (LAN, проброс порта или туннель).
- **Снапшоты в JSON** (~20 Гц). Для демо на 4 игрока хватает; для продакшена стоит
  перейти на бинарный формат и дельта-сжатие.
- **Браузер вместо Unity/Unreal.** Выбрано ради мгновенного запуска у друзей и
  одной кодовой базы симуляции для клиента и сервера. Порт на Unity запланирован
  отдельным этапом — его нужно собирать и проверять на машине с Unity Editor.
- **Производительность пост-обработки на реальных видеокартах не измерялась**
  (тесты идут на программном рендере). Если тормозит — пресет LOW.
- Звук проверялся только на отсутствие ошибок (тесты идут в headless-браузере
  без вывода звука).
